# SDSHackathon

## Running the app

Serve this directory from localhost and open `index.html`. Camera access requires a secure context such as `localhost` or HTTPS.

Choose **Sandbox** to play alone or **Invite a Friend** to connect to a peer. The Game Arcade is available in either mode; in a connected session, the shared match host coordinates game selection, controls, player hand input, and game physics.

The call page also includes paper scanning: enable **Scan paper**, show a sheet with drawings to the camera, then pinch and hold a highlighted drawing to add it to the physics scene.
