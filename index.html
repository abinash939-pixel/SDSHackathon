Sketch2Sim
Pinch thumb and index finger to draw. Shapes are identified automatically: Circle (rolls and bounces), Zigzag (acts as a bouncy spring), Closed loop (solid blob), or Open line (ramp or rod).
Pinch and hold still on an object to pick it up and move it.
Hold the white ring over an object (no pinch) to select it, then use Reverse.
Pinch and hold on the small arrow tab at the screen edge to open or hide the button panel.
Select objects first: hold the white ring over an object. Then use hand poses (hold each one still; the label at the top shows what it will do):
Thumbs up = float the selected objects (or gravity off if nothing is selected). Thumbs down = let them fall (or gravity on).
Peace sign (two fingers up) = clone the selected objects. Fist held for one second = destroy the selected objects.
Open palm = deselect all (or pause and resume if nothing is selected). Swipe an open hand sideways = erase hovered/selected object or undo last drawing.
The button panel has the same powers if you prefer it.
Mouse backup: drag to draw, double-click drops a ball, shift-click selects.
